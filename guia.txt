GUIA DE INICIO MODULOS DE LOGIN Y PERMISOS
Esta guía tendrá incluida los módulos de usuarios, este tendrá un solo usuario tipo super-admin y permisos definidos para el sistema que requieras.
Como primer paso se debe definir el menú lateral que tendrá el sistema y los permisos que existirán en el sistema.
Para cambiar el nombre de templete se modifica el themeConfig.js
Para cambiar el menú lateral se debe modificar los archivos index.js de horizontal y vertical en src/navigation esto para el frontend.
Para la iconografía se puede cambiar los iconos en referencia a este link: https://remixicon.com/
Actualizar el archivo PermissionDemoSeeder.php de api-panel/app/database/seeders, cambiar los permisos ejemplo: acción_modulo o acción-modulo, sin espacios, esto para el backend.
Para que la migración de las tanblas permisos y usuarios funcione se debe correr el siguiente comando: docker compose exec laravel php artisan db:seed --class=PermissionsDemoSeeder 
Para solo migrar todo en una nueva base de datos se debe modificar el archivo .env del api y hacer correr el comando: docker compose exec laravel php artisan migrate:fresh –seed esto si estas usando Docker, si no, directo php artisan migrate:fresh –seed
Copiar este código en databseseeder si queremos hacer correr directo todos los seeders.
class DatabaseSeeder extends Seeder
{
    /**
     * Seed the application's database.
     */
    public function run(): void
    {
        // Llamamos al seeder de permisos y roles
        $this->call([
            PermissionsDemoSeeder::class,
        ]);
    }
}
